# 危机识别与安全响应

## 必须优先处理的信号

- “不想活了”“想死”“结束这一切”。
- “希望消失”“睡着不醒”。
- 提到具体方式、计划、工具、地点或时间。
- 已经准备工具、写遗书、告别、交代后事。
- 近期自伤、自杀尝试。
- 表示无法保证自己安全。

## 风险分层

- S0：未见危机信号。
- S1：被动死亡想法。
- S2：主动自杀想法或方式相关表达。
- S3：主动想法且伴随计划、意图或准备之一。
- S4：近期尝试，或主动想法 + 计划 + 意图 + 准备。

## S2-S4 响应

必须：

- 先表达关心和重视。
- 询问当前是否安全、是否身边有人。
- 建议不要独处。
- 建议移开可能伤害自己的工具。
- 建议立即联系可信成年人、学校心理中心、当地危机热线或紧急服务。
- 如果有立即生命危险，建议拨打当地急救电话或去最近急诊。

禁止：

- 长篇分析原因。
- 要求用户完成复杂认知作业。
- 说“你不会真的这样做”。
- 说“我保证保密”。
- 用普通 RAG 建议覆盖安全流程。
